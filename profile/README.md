# AgentFetch

Field notes on giving AI agents web access they can actually use.

- **Website:** [agentfetch.live](https://agentfetch.live)
- **Blog:** [agentfetch.live/blog](https://agentfetch.live/blog) · **Guides:** [agentfetch.live/guides](https://agentfetch.live/guides)
- **Docs:** [agentfetch.live/docs](https://agentfetch.live/docs)
- **CLI:** [`agentfetch`](https://github.com/agentfetch-live/cli), live web pages as Markdown from your terminal ([docs](https://agentfetch.live/docs/cli), [npm](https://www.npmjs.com/package/@agentfetch-live/cli))

```bash
npx @agentfetch-live/cli fetch https://example.com -o text
```

A [Teneo Labs](https://agentfetch.live/imprint) project, built on the [Live Web Data API](https://livewebdata.com).
